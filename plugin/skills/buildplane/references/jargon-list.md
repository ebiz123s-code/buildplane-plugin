# Jargon list — never in member-facing text

Rewrite, don't just delete. The member reads step titles, summaries, the spec, and
every message you send them.

| Never say | Say instead |
| --- | --- |
| component, JSX, React | page, section, block |
| route, routing | page address, link |
| scaffold, boilerplate | set up, create |
| hook, state, props | (describe the behaviour: "remembers what they typed") |
| API, endpoint, payload | the connection to your CRM / the service |
| edge function, serverless, Deno | the part that runs on the server |
| schema, migration, table, RLS | where the data is stored |
| repo, commit, branch, merge | your project files, save point |
| build, compile, bundle | "check it runs" / preview |
| deploy | publish |
| DOM, render, hydrate | shows on the page |
| CSS, Tailwind, class | styling, look |
| responsive, viewport, breakpoint | on a phone / on a laptop |
| CTA | button |
| webhook | notification to another app |
| env var, secret, token, key | setting / your access key (only when they must paste one) |
| lint, type error, stack trace | a mistake I found / what went wrong |
| MCP, tool call, agent | the connection to your Genesis project |
| localhost, dev server | the preview |
| regex, JSON, YAML | (never — describe the content) |

Allowed because members already use them: **Estage, Genesis, CRM, funnel, order form,
opt-in, checkout, tag, automation, published, preview, Live Controls.**
